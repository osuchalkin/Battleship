# SeaBattle

Study C++ & SFML-project.

This game was initially created with Python and Pygame. And now I did it in C++ - as exercise in C++ and SFML 2.6. - and added AI for computer player (10 ways to place ships and ship-hunting based shooting) and win-statistics.
